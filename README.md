# Bms-tracker

Прошивки пульта BMS (Waveshare ESP32-S3-Touch-AMOLED-2.16) для обновления по воздуху.

Сами файлы лежат в **Releases**, по одному релизу на версию:

- `firmware.ota.bin` — прошивка для обновления по воздуху;
- `manifest.json` — версия и контрольная сумма (MD5) для кнопки «Проверить обновление» на пульте.

Пульт берёт последний релиз по ссылке
`https://github.com/vt750cshadow-svg/Bms-tracker/releases/latest/download/manifest.json`.
